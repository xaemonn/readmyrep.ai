# Notes

Learning notes taken while building readmyrep.ai, one file per video in the series.

These double as **interview revision material** — each file ends with an "Interview Questions" section (collapsible Q&A) and a "Key Terms" table.

## Convention

- One file per video: `vid1.md`, `vid2.md`, and so on
- Structure each file as: concepts -> gotchas -> interview questions -> key terms
- Write down what confused you, not just what worked. The questions you had are usually the ones an interviewer will ask.
