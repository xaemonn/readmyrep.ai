# Notes

Learning notes taken while building readmyrep.ai. One file per stage of the series.

These are the raw material for the project README and for explaining the project later — write freely, they get cleaned up at the end.

## Convention

- One file per stage, numbered so they sort in order: `01-...`, `02-...`
- Copy `00-template.md` when starting a new stage
- Don't worry about polish. Half-sentences are fine. Confusion is worth writing down too — the questions you had are often the most useful part later.
